# 01 环保治理设施台账

## 一、页面概述

用于各基地（厦门、重庆、菏泽）录入环保治理设施的基础信息，支持数据导入导出。
- **环境信息台账中所有页面权限说明**：各基地用户可查看所有基地数据，但仅能录入/导入/编辑/删除本基地数据。集团用户可查看、录入、导入、编辑、删除所有基地数据。

## 二、功能说明

### 1. 新增

点击「新增」打开弹窗，填写以下内容：

- **基地**：下拉选择（厦门基地 / 重庆基地 / 菏泽基地），必填
- **排放口编号**：文本输入，必填
- **排气筒名称**：文本输入，必填
- **位置**：文本输入，必填
- **排气筒高度(m)**：文本输入，必填
- **排气筒直径(m)**：文本输入，必填
- **废气/废水处理设施名称**：文本输入，必填
- **废气/废水来源**：文本输入，必填
- **污染因子**：下拉选择（非甲烷总烃 / 氮氧化物 / 二氧化硫 / 颗粒物等，数据字典维护），必填
- **排放浓度(mg/m³)**：文本输入，必填
- **处理工艺**：文本输入，必填
- **建设完成时间**：月份选择器（年+月），必填
- **设施投入费用(万元)**：文本输入，必填
- **设施建设单位**：文本输入，必填
- **设计处理风量(m³/h) / 水量(t/d)**：文本输入，必填
- **活性炭填装量(m³)**：文本输入，必填
- **活性炭更换周期**：文本输入，必填
- **活性炭进气温度**：文本输入，必填
- **活性炭排气温度**：文本输入，必填
- **吸附进气温度**：文本输入，必填
- **吸附排气温度**：文本输入，必填
- **脱附温度**：文本输入，必填
- **催化剂量**：文本输入，必填
- **风机功率**：文本输入，必填
- **风机台数**：文本输入，必填
- **备注**：文本输入

### 2. 查询

筛选条件包括：
- **基地**：下拉选择（全部 / 厦门基地 / 重庆基地 / 菏泽基地）
- **关键字**：文本输入，支持按「排放口编号 / 排气筒名称 / 位置 / 设施名称」模糊查询
- **污染因子**：下拉选择（数据字典维护）
- **建设完成时间**：月份区间选择（起始月份 - 结束月份）

### 3. 下载模板及导入

-点击「下载模板」下载导入用 Excel 模板。
-模板列头为：基地、排放口编号、排气筒名称、位置、排气筒高度(m)、排气筒直径(m)、废气/废水处理设施名称、废气/废水来源、污染物因子、排放浓度(mg/m³)、处理工艺、建设完成时间、设施投入费用(万元)、设施建设单位	、设计处理风量(m³/h) / 水量(t/d)	、活性炭填装量(m³)	、活性炭更换周期、	活性炭进气温度	、活性炭排气温度	、吸附进气温度、吸附排气温度、	脱附温度、催化剂量、风机功率、风机台数、备注。

-点击「导入」上传 Excel 文件，按模板格式解析并批量新增记录。

- 校验基地、污染因子、建设完成时间等字段的合法性
- 失败行给出错误提示

### 4. 导出

点击「导出」按当前筛选条件导出列表数据为 Excel，导出字段与列表字段一致（不含操作列）。

## 三、数据唯一性

- 同一基地、同一排放口编号、同一污染因子。新增/导入时若相同数据已存在，直接覆盖。
